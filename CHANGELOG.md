# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-16

### Added

- Initial release with 357 SKILL.md files across 15 domains
- 250+ R package skills covering data manipulation, visualization, ML, web, spatial, network, NLP, stats, bio, dev, parallel, syntax, language API, logging, and learning
- 18 curated reference guides (R for Data Science 2e, Advanced R 2e, R Graphics Cookbook, Tidyverse Ecosystem, Bioconductor, and more)
- Main SKILL.md entry point with quick reference for R workflows
- Package update scripts
- GitHub Actions CI workflow (claude-review)
- Issue templates (bug report, feature request)
- Pull request template
- CONTRIBUTING.md guidelines
